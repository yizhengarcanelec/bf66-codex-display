# BF66 Codex Display 使用指南

本文适用于 2.3 版本。程序支持 USB 和同一 Wi-Fi 传输，以及自定义画面、GPT Usage、月薪喵桌宠三种模式。

## 1. 准备设备

1. 在 BF66 中打开“设置 → 关于设备”，连续点击版本号以启用开发者选项。
2. 在开发者选项中开启 USB 调试。
3. 使用可传输数据的 USB 线连接电脑，解锁 BF66。
4. 首次连接时，在 BF66 上勾选“始终允许”并确认 USB 调试授权。

## 2. 安装和启动

1. 保持控制端、`BF66Display.apk` 与 `tools/platform-tools` 的相对目录不变。
2. 启动 `BF66显示控制台.exe`。
3. 点击“安装显示端到 BF66”，或使用 ADB 安装 APK。
4. 控制端检测到设备后会自动建立 USB 通道并打开显示端。

首次启动会在控制端目录生成随机的 `bf66-connection.key`。这是本机配对凭据，不要分享或提交到 Git。

## 3. 三种显示模式

### 自定义画面

可以设置标题、正文、颜色、字号和时钟，并选择 JPG、PNG、WebP、GIF、BMP 图片。“完整显示”保留整张图片，“铺满裁剪”填满屏幕。

### GPT Usage

展示今日 Token、INPUT、OUTPUT、CACHE、周剩余额度和重置时间。数据约每 5 秒更新一次，仅从电脑本地 Codex 记录计算；对话正文不会发送到 BF66。

### 月薪喵桌宠

- 轻触头部：被抚摸动画。
- 轻触身体：生气反馈。
- 双击：开心跳跃和粒子。
- 长按：睡觉 / 飘走动画。
- 拖动：小范围跟随，松手后自动回位。

有 Codex 新活动时，月薪喵进入工作动画；超过 10 分钟无新会话时进入休息动画。桌宠界面显示当前时间，不显示绿色触控指示圆点，所有反馈完全静音。

## 4. 横竖屏

在控制台“方向”选项中选择横屏或竖屏：

- 横屏：时钟顶部居中、气泡在左、月薪喵在右。
- 竖屏：时钟位于顶部、气泡位于时钟下方、月薪喵位于中下方。

方向设置只应用于 BF66 显示程序；退出程序后不会永久锁定 Android 系统方向。

## 5. USB 与 Wi-Fi

程序优先使用 USB：

1. USB 连接时通过 ADB reverse 访问电脑端口 8787。
2. 首次 USB 配对后，BF66 会保存配对信息。
3. BF66 和电脑连接同一 Wi-Fi 后，拔掉 USB 可以自动寻找电脑。
4. Windows 防火墙弹窗只建议允许“专用网络”。

右上角的 `USB LIVE`、`USB` 或 `WI-FI` 表示当前传输通道。

## 6. 退出与卸载

- 退出显示模式：在 BF66 上按返回键或主页键。
- 删除电脑端：关闭控制台后删除整个程序目录。
- 卸载 BF66 端：设置 → 应用 → BF66 显示屏 → 卸载。

## 7. 常见问题

- **未检测到设备**：确认数据线支持数据传输，设备已解锁且 USB 调试已授权。
- **停留在等待页面**：保持控制台运行，点击“连接并打开 BF66”。
- **Wi-Fi 无法连接**：确认两端处于同一可信局域网，并先完成一次 USB 配对。
- **图标没有立即刷新**：重新安装 2.3 APK，必要时重启桌面启动器或设备。
- **Windows 安全提示**：个人构建通常没有商业代码签名证书，可在核对源码后自行构建。
