# 使用指南

## 1. 安装显示端

1. 在 BF66 上开启“开发者选项”和“USB 调试”。
2. 用可传输数据的 USB 线连接 BF66 与电脑，并在设备上允许调试授权。
3. 将构建得到的 `BF66Display.apk` 安装到设备，或在控制台中点击“安装显示端到 BF66”。

## 2. 启动控制端

1. 保持控制台程序、APK 与 `tools/platform-tools` 的相对目录不变。
2. 打开 Windows 控制台。
3. 首次启动会在程序目录生成随机的 `bf66-connection.key`；该文件用于设备配对，不应分享或提交到版本库。
4. 控制台检测到 BF66 后会自动建立 USB 通道并打开显示端。

## 3. 三种显示模式

### 自定义画面

设置标题、正文、颜色、字号、时钟与背景图片。“完整显示”保留整张图片，“铺满裁剪”填满屏幕并裁去溢出部分。

### GPT Usage

展示今日 Token、INPUT、OUTPUT、CACHE、周剩余额度和重置时间。控制端每约 5 秒读取一次本机摘要；它不会把对话正文发送到 BF66。

### Codex 桌宠

- 轻触头部：挥手回应。
- 轻触身体：惊讶回应。
- 连续轻触：跳跃并释放粒子。
- 长按：暂时休息。
- 拖动：小范围跟随手指，松手后回到屏幕中下方。

桌宠会依据 Codex 活动在工作、待机和休息之间切换。用量更新只改变胸口灯光，不弹文字；所有交互完全静音。

## 4. 横竖屏

在“方向”中选择“横屏”或“竖屏”。旋转只应用于 BF66 显示程序；退出显示程序后不会永久锁定设备系统方向。

## 5. USB 与 Wi-Fi

连接优先级为 USB 高于同一 Wi-Fi：

1. 插入 USB 时，控制端使用 ADB reverse 传输。
2. 首次 USB 配对成功后，BF66 会保存配对信息。
3. BF66 与电脑位于同一 Wi-Fi 时，拔掉 USB 后可自动寻找电脑控制端。
4. Windows 防火墙询问时，只建议为“专用网络”放行。

画面角落显示 `USB LIVE`、`USB` 或 `WI-FI`，用于标识当前通道。

## 6. 退出显示模式

在 BF66 上按返回键或主页键即可退出显示程序，设备会恢复正常 Android 使用状态。

## 7. 常见问题

- 未检测到 BF66：确认使用数据线、设备已解锁且允许 USB 调试。
- 停留在等待页面：保持控制台运行，重新点击“连接并打开 BF66”。
- Wi-Fi 无法连接：确认两台设备位于同一局域网，并先完成一次 USB 配对。
- Windows 安全提示：个人构建通常没有商业代码签名证书，可核对源码后自行构建。
