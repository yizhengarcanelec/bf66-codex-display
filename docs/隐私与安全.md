# 隐私与安全

## 数据流

控制端会读取本机 Codex 会话目录中的结构化用量记录，用于计算 Token 汇总和最近活动时间。它不会把会话正文展示在 BF66 上，也不会把这些数据上传到外部服务器。

传给 BF66 的内容仅包括：当前显示模式、方向、自定义文字/图片、用量汇总、最近活动时间和界面版本号。

## 配对密钥

`bf66-connection.key` 是首次运行时随机生成的本地配对凭据。HTTP 状态、显示页面和媒体接口都需要该密钥。请勿共享、截图或提交这个文件；如果怀疑泄露，关闭程序后删除它，再次启动即可生成新密钥，并通过 USB 重新配对设备。

## 网络边界

- USB 模式通过 ADB reverse 访问电脑本机端口。
- Wi-Fi 模式只用于同一局域网连接，但控制服务会监听端口 8787。
- 建议仅在可信的专用网络中启用 Wi-Fi，并在 Windows 防火墙中拒绝公用网络访问。
- 当前实现使用配对密钥鉴权，但局域网传输不是 HTTPS；不要在不可信网络中使用 Wi-Fi 模式。

## 仓库排除内容

本仓库的忽略规则覆盖以下内容：

- 配对密钥和签名密钥；
- Android `local.properties`；
- `.NET` 与 Gradle 构建缓存；
- APK、AAB、PDB 和日志；
- 本地 ADB 工具副本；
- 编辑器和操作系统生成的个人配置。

发布前还应搜索绝对本机路径、用户名、访问令牌、设备序列号和私钥头，确认没有误提交。
