BF66 定制显示程序 2.4
======================

用途
----
在 Windows 电脑上设置梵沐 BF66 显示 GPT Usage、自定义文字/图片、互动桌宠和酷狗音乐播放信息。
画面可以通过 USB 或同一 Wi-Fi 传输，不需要互联网。
无线访问使用随机配对密钥，未配对的设备无法读取显示内容。

本机状态
--------
“BF66 显示屏”应用已经安装到当前连接的 BF66 上。
设备已经允许 USB 调试，正常情况下以后只要连接数据线并打开电脑控制台即可。

使用步骤
--------
1. 保持整个“BF66定制显示程序”文件夹完整，不要只单独移动 EXE。
2. 用数据线连接 BF66 和电脑，解锁 BF66。
3. 双击“BF66显示控制台.exe”。
4. 控制台会自动连接并打开 BF66 上的显示应用。
5. 默认进入“GPT Usage”模式，每 5 秒同步今日 Token 和周额度。
6. 在“方向”中选择“竖屏”或“横屏”，BF66 显示应用会立即旋转并重新排版。
7. 在“显示模式”中选择“自定义画面”，可输入标题、正文并选择颜色或图片。
8. 选择“桌宠”后，可直接在 BF66 触屏上与月薪喵互动。
9. 选择“音乐播放器”后，程序会自动切换 BF66 为横屏；请在电脑酷狗中播放歌曲。

GPT Usage 模式
--------------
显示今日 Token 总量、INPUT、OUTPUT、CACHE、周剩余额度、已用比例和重置时间。
读取逻辑与 GPT Usage Widget v0.4.0 一致，数据来自电脑本地 Codex 会话记录。
刷新周期约 5 秒；电脑控制台必须保持运行。
横屏时会自动切换为左右布局；切换方向只影响“BF66 显示屏”应用，退出后不会锁定 MP4 的系统方向。

自定义画面模式
--------------
支持 JPG、PNG、WebP、GIF、BMP 图片。
“完整显示”会保留完整画面，“铺满裁剪”会填满屏幕并裁去超出部分。

桌宠模式
--------
桌宠角色为“月薪喵”，默认与互动动画来自 DesktopPet-Miao 项目，并针对 BF66 触屏重新适配。
轻触头部：进入被抚摸动画；轻触身体：生气回应；双击：开心跳跃并释放粒子；长按：进入睡觉动画。
可以小范围拖动桌宠；拖动时月薪喵会倾斜并切换表情，松手后弹回屏幕中下方并做落地动作。
桌宠会读取本地 Codex 会话活动：有新工作时切换到处理任务动画并显示一句简短气泡，超过 10 分钟没有新会话时睡觉休息。
GPT Usage 更新不会弹出文字，也不会显示绿色圆点或触控位置标记；桌宠完全静音。
桌宠界面会显示当前时间。竖屏时钟位于顶部、气泡位于时钟下方；横屏时钟位于顶部中央、气泡在左、月薪喵在右，三者不会互相遮挡。

音乐播放器模式
--------------
音乐播放器仅支持横屏。它从 Windows 的系统媒体会话读取酷狗的歌曲名、歌手、专辑、专辑封面、播放/暂停状态、进度和时长，并在 BF66 显示动态渐变、唱片动效、歌词过渡与进度条。
BF66 触屏可控制上一首、播放/暂停和下一首。若酷狗没有向 Windows 提供媒体会话，画面会显示“等待酷狗播放”，不会读取或控制其他播放器。

进度条支持直接触摸拖动。松手后会请求酷狗跳转到对应播放位置；若该酷狗版本拒绝系统媒体会话的跳转指令，状态栏会给出提示。

封面由酷狗的 Windows 媒体会话提供；若个别歌曲未提供封面，播放器会自动保留渐变首字母卡片，不影响其他功能。

动态歌词会自动读取控制端同级的 `Lyrics`、`我的音乐\Lyrics`，以及本机酷狗库 `D:\Kugou\Lyric` 中的标准 UTF-8 `.lrc` 或酷狗 `.krc` 文件。文件名应包含歌曲名，例如 `歌手 - 歌曲名.lrc`。KRC 会在电脑端自动解码、转换为 LRC 并缓存到 `Lyrics\Cache`，不上传文件内容。没有匹配歌词时仍可正常显示歌曲信息和操作控制。

歌词匹配会综合歌手、歌名和文件更新时间，短歌名不会再误选其他歌曲。当前歌词过长时会在行内平滑向左滚动；换到下一句时，上一句、当前句和下一句会一起做缓动上滑过渡。

播放器会优先使用酷狗交给 Windows 的真实进度与总时长。若该酷狗版本只提供歌曲信息、封面和播放状态（时间轴为 0），则会从歌词的 `[total]` 标签或在线结果补齐总时长，并从识别到该曲目时起连续计时；状态栏会明确显示“酷狗未提供时间轴”。在这种情况下，重新切歌或从头播放可让估算进度从 0 开始，拖动酷狗进度条无法被 Windows 媒体会话获知。

如需自动匹配歌词，可勾选控制台的“允许在线匹配歌词”选项。此选项默认关闭；勾选后仅向 LRCLIB 发送当前歌曲名、歌手和时长，不发送设备信息、播放记录或本地文件。匹配到的歌词仅缓存到本机 `Lyrics\Cache` 文件夹，取消勾选后不会继续联网请求。

程序图标
--------
Windows 控制端和 BF66 Android 显示端统一使用“月薪喵看手机”图标。
图标母图已经移除截图中的绿色触控指示圆点；Windows EXE、窗口图标与 Android 各分辨率启动图标均使用同一母图生成。

连接方式
--------
程序按“USB > 同一 Wi-Fi”的顺序自动选择连接。
重新插入 USB 后会自动切回 USB；拔掉 USB 后会自动寻找同一 Wi-Fi 下的电脑。
BF66 画面右上角显示“USB LIVE”或“WI-FI”，表示当前通道。

首次 Wi-Fi 配对
--------------
1. 必须先用 USB 成功连接一次，让控制端把随机密钥保存到 BF66。
2. 将 BF66 和电脑连接到同一个 Wi-Fi 局域网。
3. 拔掉 USB 后手动打开 BF66 上的“BF66 显示屏”，它会自动寻找电脑。

如果 Windows 防火墙首次询问，请只允许“专用网络”。同一 Wi-Fi 模式要求两台设备位于同一个局域网。

按钮说明
--------
立即更新画面：把当前内容推送到 BF66。
连接并打开 BF66：重新建立 USB 通道并打开显示应用。
安装显示端到 BF66：换设备或卸载应用后重新安装。

常见情况
--------
显示“等待 MP4 允许 USB 调试”：查看 BF66 屏幕，勾选“始终允许”，再点“允许”。
显示“没有检测到 BF66”：重新插拔数据线，确认使用的是数据线而不是充电线。
BF66 停留在等待画面：保持电脑控制台运行，点击“连接并打开 BF66”。
Windows 首次运行提示保护电脑：这是因为本程序没有购买商业代码签名证书；可选择“更多信息”后运行。

卸载
----
电脑端：删除整个程序文件夹即可。
BF66 端：设置 > 应用 > BF66 显示屏 > 卸载。

技术信息
--------
适配设备：梵沐 BF66，Android 13，720 × 1280；当前版本 2.4。
USB 通信：ADB reverse；Wi-Fi 通信：同一局域网内自动发现，端口 8787。
显示内容和选择的图片只在电脑与已配对 BF66 之间传输。
月薪喵素材来源与许可说明见 THIRD_PARTY_NOTICES.md。
